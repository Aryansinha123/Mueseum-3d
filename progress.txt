1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
The project is a web-based 3D Virtual Museum with interactive exhibition wings,
first-person exploration, orbit inspection, dynamic GLB 3D model loading with
automatic bounding-box scaling, and an architecture ready for RAG-powered AI
Curator integration.

The stack comprises:
  - Frontend 3D Engine: Next.js 16 (App Router), React 19, Three.js, 
                        React Three Fiber (@react-three/fiber v9), Drei (@react-three/drei v10)
  - Styling & UI Components: Tailwind CSS v4, Lucide React icons
  - Python API / Utilities: Smithsonian Open Access API Search Script (1.py)
  - Backend Architecture Plan: FastAPI, MongoDB, ChromaDB (Vector DB), Gemini LLM (RAG)

2. IMPLEMENTED MODULES & FEATURES
--------------------------------------------------------------------------------

[A] 3D ARCHITECTURAL ENVIRONMENT & LIGHTING
    • Central Rotunda Lobby: Connecting hub for all wings.
    • Gallery 1 (Classical Antiquities): Left wing housing prehistoric & classical items.
    • Gallery 2 (Medieval & Epigraphic Treasures): Right wing housing medieval regalia & tablets.
    • Gallery 3 (Ancient Wonders Hall): Rear wing housing monumental exhibits.
    • Main Entrance Portal: Architectural doorway with decorative trim.
    • Structural Features: Polished marble floor with grid reflections, multi-room walls
      with archways, ceiling structures, warm track lights, overhead spotlights, and ambient fog.

[B] DUAL-MODE CONTROLS & NAVIGATION SYSTEM
    • First-Person Walking Mode: WASD + Arrow key navigation with mouse look via PointerLockControls
      and spatial collision boundaries.
    • Orbit Inspect Mode: Smooth camera transition to focus directly on selected exhibit pedestals
      with full 360-degree rotation and zoom.
    • Interactive 2D Map Teleportation: Click-to-teleport feature from the floorplan overlay.

[C] DYNAMIC 3D ARTIFACT & MODEL MANAGEMENT PIPELINE
    • Centralized Metadata Store (src/data/artifacts.js): Defines position, rotation, scaling,
      historical periods, institution details, licenses, and AI context for 5 exhibit slots.
    • Decoupled Architecture: Museum -> ArtifactManager -> Pedestal -> Artifact -> AutoFitModel.
    • Auto-Scaling Normalizer (AutoFitModel.jsx): Calculates Three.js Box3 bounding boxes,
      normalizes model height/scale to fit pedestals (~0.65m height), and aligns Y-bottom to pedestal surface.
    • Procedural Fallback System (ArtifactPlaceholder.jsx): Renders glowing low-poly 3D geometric
      placeholders with development notices if GLB models are missing, ensuring zero crash risk.

[D] GLASSMORPHIC 2D OVERLAY UI & CONTROLS
    • Museum HUD Header (MuseumHUD.jsx): Live zone location indicator, control mode toggle,
      map button, controls guide trigger, and camera reset button.
    • Exhibit Detail Drawer (ArtifactInfo.jsx): Slide-over panel displaying exhibit title,
      period, origin, institution, description, legal license link, and AI Curator tab preview.
    • Interactive Floorplan Map (MuseumMap.jsx): 2D canvas/SVG floorplan showing live visitor location,
      room labels, exhibit dots, and one-click teleportation.
    • Controls Overlay (ControlsOverlay.jsx): Keyboard & mouse control guide modal.
    • 3D Asset Preloader (LoadingScreen.jsx): Clean loading screen with progress feedback.

[E] EXTERNAL API & RESEARCH TOOLS
    • Smithsonian Open Access API Integration (1.py): Python script using `requests` to query
      the Smithsonian Open Access API (`https://api.si.edu/openaccess/api/v1.0/search`) for 3D model metadata and images.

[F] ARCHITECTURE & INTEGRATION DOCUMENTATION
    • Docs/arch.txt: System architecture diagram (User -> Web App -> Selected Exhibit -> FastAPI -> ChromaDB + Gemini RAG).
    • Docs/artifactsintegration.md: Step-by-step master integration guide for adding new 3D models.
