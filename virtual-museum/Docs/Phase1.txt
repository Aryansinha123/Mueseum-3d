5. RETRIEVAL SYSTEM
===================

Create:

backend/rag/retrieval.py

Implement cosine similarity manually using NumPy or a simple transparent implementation.

The main function should conceptually be:

retrieve(question)

It should:

1. Convert the user question into an embedding.
2. Calculate cosine similarity against every artifact embedding.
3. Find the artifact with the highest similarity.
4. Return:

   * artifact ID
   * artifact name
   * gallery
   * similarity score
   * description
   * evidence text

Example result:

{
"artifact_id": "...",
"artifact_name": "...",
"gallery": "History",
"score": 0.82,
"description": "...",
"evidence": "..."
}

Do NOT call any LLM.

==================================================
6. IMPORTANT — DO NOT CALL THE SCORE "CERTAIN
CONFIDENCE" YET
===============

For Phase 1, treat the cosine similarity as:

similarity_score

It may later be used as the basis for the confidence mechanism in Phase 2.

Do not claim that a cosine similarity of 0.8 automatically means 80% confidence.

Use terminology such as:

"retrieval similarity score"

This distinction is important for the research methodology.
