==================================================
6. PINCH TO SCALE
==================================================

Implement two-finger pinch.

Calculate the distance between the two active touches.

Initial distance:

d0

Current distance:

d1

Scale proportionally:

scale = initialScale * (d1 / d0)

Clamp the result.

Example:

minimum scale = 0.2
maximum scale = 3.0

Adjust these values based on the existing artifact normalization.

Scaling must feel smooth.

Do not jump in size when the second finger is added.
