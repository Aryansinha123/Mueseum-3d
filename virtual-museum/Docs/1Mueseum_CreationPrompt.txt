# Build a Complete 3D Virtual Museum Using Three.js

You are an expert full-stack web developer specializing in **Next.js, React, Three.js, React Three Fiber, 3D environments, and interactive museum experiences**.

Build a complete, polished **3D Virtual Museum web application** from scratch.

## 1. Core Project Goal

The application is a **virtual museum**, not a normal website with 3D elements.

The main experience should be a navigable 3D museum environment containing multiple artifact locations.

The final scene should conceptually look like:

```
                VIRTUAL MUSEUM
```

┌──────────────────────────────────────────────────────┐
│                                                      │
│    🗿 ARTIFACT 1                  🏺 ARTIFACT 2      │
│                                                      │
│                                                      │
│                  🖼️ ARTIFACT 3                       │
│                                                      │
│                                    🛕 ARTIFACT 4    │
│                                                      │
│                    🗿 ARTIFACT 5                     │
│                                                      │
└──────────────────────────────────────────────────────┘

The artifacts must eventually exist as **real 3D objects inside the same Three.js scene**.

Do NOT use iframes for the artifacts.

The Smithsonian Voyager iframe may be used only as a future reference/inspiration. The architecture must allow us to replace placeholder artifacts with actual `.glb/.gltf` models later.

# 5. Visual Design

Make the museum look like a modern digital cultural museum.

Use:

* spacious galleries
* realistic proportions
* clean walls
* polished floors
* display pedestals
* framed information panels
* subtle architectural details
* ceiling lights
* exhibit spotlights
* directional lighting
* warm neutral museum materials
* clear gallery separation

Do not make it look like a video game level.

The visual style should feel like:

"modern museum + digital heritage experience"

Avoid excessive neon, sci-fi effects, glowing objects, or gaming aesthetics.

---

# 6. Lighting

Implement a proper Three.js lighting setup.

Use:

* Ambient/Hemisphere lighting
* Directional light
* Point/spot lights for exhibits

Each artifact display should have focused lighting.

Artifacts should visually stand out from the environment without excessive bloom or glow.

Create a reusable exhibit-light component if useful.

---

# 7. Camera and Navigation

The user must be able to explore the museum.

For the initial desktop version implement:

### Desktop

* mouse look / orbit controls
* zoom
* pan
* smooth camera movement
* reasonable camera limits
* prevent the camera from going through walls as much as practical

Prefer an immersive first-person museum navigation experience over a simple static orbit camera.

The user should feel like they are inside the museum.

If full first-person controls are implemented, provide:

* WASD movement
* mouse look
* optional pointer-lock
* movement speed control
* collision boundaries where practical

Also provide a simple fallback camera control if pointer lock is unavailable.

# 12. Artifact Coordinates

Every artifact must have a configurable 3D position.

Use the Three.js coordinate system:

x = left/right
y = vertical
z = depth

Do not hardcode positions across multiple components.

Keep artifact configuration in:

`src/data/artifacts.js`

This will later allow us to connect:

artifact_id → 3D model → MongoDB → ChromaDB → AI curator.

# 17. Performance

Optimize the application for normal laptops and smartphones.

Important requirements:

* avoid unnecessarily high polygon counts
* use compressed textures where possible
* avoid excessive lights
* use reusable materials
* avoid rendering unnecessary objects
* use reasonable shadow settings
* use LOD or simplified geometry where useful
* lazy-load artifact models where practical

The final project will eventually contain multiple museum artifacts, so design for scalability.
