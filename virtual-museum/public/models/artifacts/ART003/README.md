## Description

The Morse-Vail Telegraph Key is an important historical communication device associated with the development of electrical telegraphy. Telegraph keys were used by operators to manually transmit electrical signals representing characters through Morse code. The development of telegraph technology played a major role in long-distance communication during the nineteenth century.
