# 🏛️ Virtual Museum RAG Core & XAI Layer — Backend

This directory contains the **Phase 1 RAG Core** and **Phase 2 Confidence-Aware Explainable RAG (XAI)** backend for the **Virtual Museum AR/VR Experience**.

The goal of Phase 2 is to enforce a **strict pre-LLM relevance threshold gate** that prevents hallucinations by refusing out-of-scope questions before any LLM API call is made.

---

## 🎯 System Architecture

```text
USER QUESTION
      │
      ▼
EMBED QUESTION (SentenceTransformer: all-MiniLM-L6-v2)
      │
      ▼
MANUAL COSINE SIMILARITY (NumPy vs 15 Artifact Vectors)
      │
      ▼
BEST MATCHING ARTIFACT + RELEVANCE SCORE
      │
      ▼
┌───────────────────────────────────────────────┐
│ relevance_score >= RELEVANCE_THRESHOLD (0.50)? │
└───────────────────────┬───────────────────────┘
                        │
         ┌──────────────┴──────────────┐
         │                             │
       YES                            NO
         │                             │
         ▼                             ▼
   [LLM: CALLED]                 [LLM: NOT CALLED]
Call Grounded Gemini API       Return Fixed Refusal Payload:
  with ONLY retrieved          "This information is not available
  artifact context.            in the curated museum knowledge base."
         │                             │
         ▼                             ▼
 { Answer, Source,             { Answer, Source: null,
   Score, Evidence,              Score, Evidence: null,
   Refused: false }              Refused: true }
```

## 🛠️ Installation & Setup

### 1. Activate Environment & Install Dependencies
```bash
cd backend
.\venv\Scripts\Activate.ps1

pip install -r requirements.txt
```
*(Dependencies: `sentence-transformers`, `numpy`, `google-genai`, `python-dotenv`)*

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and set your Google Gemini API Key:
```bash
cp .env.example .env
```
Inside `.env`:
```ini
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

## 🔬 Research Terminology & Metrics

- **Retrieval Similarity Score**: The raw cosine similarity value between query and artifact vector embeddings.
- **Relevance Threshold**: The decision boundary ($\text{THRESHOLD} = 0.50$) gating LLM execution.
- **Refusal Mechanism**: Automatic pre-LLM rejection for queries scoring $< 0.50$, returning `refused: true` and `llm_called: false`.
- **Grounded Answer**: Answer generated by the LLM constrained strictly to the retrieved artifact description via system prompt.

## 🚫 Boundaries & Non-Goals for Phase 2

- ❌ No frontend modifications (Next.js / WebXR remains completely untouched).
- ❌ No vector DBs or heavy agent frameworks (No LangChain, ChromaDB, FAISS).
- ❌ Phase 3 Personalization, Phase 4 API Wiring, and Phase 5 Benchmark suites are NOT included in Phase 2.
