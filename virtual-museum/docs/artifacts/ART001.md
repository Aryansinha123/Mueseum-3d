## Artifact Description

A masterwork neoclassical marble sculpture modeled in 1866 by renowned African-American and Native American sculptor Edmonia Lewis. Inspired by Henry Wadsworth Longfellow's epic 1855 poem 'The Song of Hiawatha', it depicts an Ojibwe arrow maker weaving arrows alongside his seated daughter Minnehaha.

## 3D Asset Download & Setup Instructions

1. Visit the official Smithsonian 3D portal at [https://3d.si.edu](https://3d.si.edu) or search for **"Handaxe from India"** / **"Isampur"** on the Smithsonian Human Origins 3D collection.
2. Select the **Downloads** menu on the model page.
3. Download the **GLB** / **GLTF** model package (e.g. `Low-Resolution GLB` or `High-Resolution GLB`).
4. Rename the downloaded file to `model.glb`.
5. Place the file inside your project directory at:
   `virtual-museum/public/models/artifacts/ART001/model.glb`
6. (Optional) Save a preview thumbnail image as `preview.jpg` in the same folder.

## Runtime Behavior & Fallback Architecture

- When `public/models/artifacts/ART001/model.glb` is present:
  - The application automatically loads and scales the real Smithsonian 3D model onto the display pedestal.
- When `public/models/artifacts/ART001/model.glb` is missing:
  - The application displays the procedural 3D placeholder exhibit.
  - A development console message is output:
    `"ART001 model not found. Place the Smithsonian GLB at public/models/artifacts/ART001/model.glb"`
